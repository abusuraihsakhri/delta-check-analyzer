Evaluation

Submit paired results to view absolute change, percentage change and method-specific flags. A missing threshold is reported as not evaluated, never as a pass.

RCV: √2 × z × √(CVi² + CVa²). This is a statistical threshold, not a clinical diagnosis or posterior probability of biological change. Time-weighted RCV is not used in this browser version.
Data remain in this browser tab. No server request, analytics, external fonts or persistent browser storage are used. Export is initiated locally. Educational/research use only; not validated as a laboratory information system.
